are kept out of the public `/docs` site (only `content/docs/*.mdx` is
published); read them here in the repo.

|---|---|
| [getting-started.md](getting-started.md) | local run, scripts, tests, deploy and secrets |
| [admin.md](admin.md) | admins, bootstrap login, secrets, rate-limit bindings, media bucket |
| [reddit.md](reddit.md) | the Reddit sync (`scripts/sync-reddit.mjs`) and `reddit-fetch` |
| [hakios-registry.md](hakios-registry.md) | the HakiOS ports registry sync |
| [hackiosx.md](hackiosx.md) | the hackiosx.dev sync |

Links in these files that start with `/docs/` point at the public docs site.
